铁底湾 IV · 联机骰子界面收起/展开补丁 v2.1

适用：此前安装的 IBS_LAN_Dice_v2_CPU_RDSEED.zip（online 分支联机房间）。

修改内容：
- 在全屏骰子弹窗右上角增加【— 收起】。
- 收起后全屏遮罩完全隐藏，游戏界面可正常查看、点击；右下角出现【骰子判定 / 展开】浮动按钮。
- 浮条显示【轮到你投骰 / 等待某方投骰 / 骰子滚动中 / 裁决中 / 结果已揭晓】等状态。
- 点击浮条可恢复原有骰子与右侧规则表。
- 收起后停止本地骰子动画；轮询从每 300 毫秒一次改为每 850 毫秒一次（空闲 1500 毫秒），且每次请求完成后再发下一次，降低页面压力。
- 保持服务器分配的投骰权、骰点结果、高亮、动画语义、CPU RDSEED 随机数生成机制不变。

安装步骤：
1. 在主机联机服务器终端按 Ctrl+C 停止。建议先备份存档。
2. 将整个 IBS_Dice_Collapse_v2_1 文件夹解压到游戏根目录，例如：
   C:\Users\19195\Desktop\iron-bottom-sound\IBS_Dice_Collapse_v2_1\
3. 在游戏根目录 PowerShell 执行：
   python .\IBS_Dice_Collapse_v2_1\install_dice_ui.py
4. 重启原本的联机服务器（沿用你原来的 RDSEED 启动方式）。
5. 双方浏览器 Ctrl+F5 刷新，进入等待投骰的阶段，检查【收起】和【展开】。

不需要：重新运行 patch_frontend.py、pnpm build、build_cpu_rng.bat。
不修改：lan_server.py、lan_dice.py、ibs_cpu_rng.dll、原版规则、房间文件和 SQLite 数据库。

重要：本补丁解决的是骰子全屏遮罩妨碍查看与操作、前端过高轮询频率问题。它不会让规则引擎绕过等待骰点。
如果双人都不能投、连续数分钟无进展，请检查主机终端异常、/lan/dice/state 的 status 和 error。
特别是若 status 为 waiting 且 may_roll=false，可能表示轮到另一个阵营；若双方都显示 false，属于权限/身份同步问题，而不是界面收起问题。

测试：使用 Chromium 无头浏览器 + 模拟接口，验证折叠/展开、折叠后原战场按钮可点击、下一方状态同步、禁止非授权投骰、动画暂停、结果高亮、闲置自动关闭。未在您的真实两台 Windows 主机上完成实机验收。
