# 铁底湾的回响 IV · 局域网联机准备大厅 v3

适用于已安装 v2「卡回合同步修复版」的 Windows 用户。**这是 v2 的升级补丁，不是原版游戏完整安装包。**

## 功能

- 两方使用原邀请凭证进入同一个 `/lan/lobby` 页面，先选剧本、规则、随机种子，再分别确认准备。
- 通过原项目 `/scenarios`、`/custom-scenarios`、`/scenarios/{id}/briefing` 读取可选剧本和简报，使用原项目 `/games` + `GameOptions` 创建游戏。
- 双方共享同一套服务器保存的配置；任何一方更改配置，双方准备状态均清零。
- 双方都确认后，仅由服务器创建新游戏（自动防止同一版本重复创建）。
- 现有对局未被删除，仍可点击「进入当前对局」继续；新游戏覆盖的是**联机房间的当前指针**，不是数据库记录。已有存档仍在原版 SQLite 中，但原房间链接只指向最新对局。
- 旧联机封存、自动推进、失败重试逻辑保持不变；阵营票据及权限隔离保持不变。
- 原版页面有「返回联机准备大厅」浮动入口，也可手动访问 `/lan/lobby`。

## 与原版选择界面的关系

这是一个**新做的联机准备大厅页面**，使用原版的剧本 ID、剧本简报和规则选项字段，但**不是原版 React 首页的逐像素复制**。支持内置剧本及本机可读取的自定义剧本、夜战可选规则、随机种子、风暴格、雷达变体、真实编队指挥、战报。

当前联机模式固定 `mode=hotseat`、`ruleset_version=night-v2`、禁用 `command_delay_mode`；不支持对局中编辑自定义剧本、LLM 对战或在线管理员操作。规则组合的最后合法性由原版 `/games` 接口检查。

## 在主机升级（建议保留当前存档）

1. 两名玩家退出游戏页，在运行 `lan_server.py` 的黑色窗口中按 `Ctrl+C` 关闭联机服务器。
2. 打开 PowerShell，进入游戏根目录：

```powershell
cd "C:\Users\19195\Desktop\iron-bottom-sound"
Copy-Item .\lan_server.py .\lan_server.py.before-lobby-v3.bak
Copy-Item .\backend\lan-duel-room.json .\backend\lan-duel-room.json.before-lobby-v3.bak
```

3. 将压缩包里的 `lan_server.py` 和 `lan_lobby.html` 解压到**游戏根目录**，让新版 `lan_server.py` 覆盖旧文件，保证 `lan_lobby.html` 与 `lan_server.py` 在同一级目录。
4. 检查语法并启动：

```powershell
python -m py_compile .\lan_server.py
python .\lan_server.py
```

也可以双击已有的 `启动局域网双人对战.bat`。

**不要运行「新建联机房间.bat」**：当前现有房间、玩家阵营令牌和对局会被新房间配置替代。不要删除 `backend/lan-duel-room.json` 或 SQLite 数据库。

**升级 v3 不需要重新执行 `patch_frontend.py`，也不需要重新 `pnpm run build`。** 原来能玩的前端 `frontend/dist/index.html` 继续使用。

## 双人使用

1. 双方打开之前已有的邀请链接，或在已登录的浏览器打开：`http://主机IP:8765/lan/lobby`。
2. 先查看旧对局。若只想继续旧局，点击「进入当前对局」。若要开新局，先共同选剧本和规则。
3. 任一方编辑设置后点击「保存并同步规则」。对方页面每约 2 秒自动同步。
4. 双方各自点击「我已确认，准备完毕」。仅当双方均确认后，主机生成新对局，两人跳转到各自阵营战场。
5. 后续回合的订单封存及推进逻辑与 v2 相同。

## 排错

- **出现 401**：浏览器尚未通过阵营邀请链接登录，请重新使用自己的邀请链接；不要混用两个阵营的链接。
- **出现 409**：对方刚改了规则；点击「撤销本地修改 / 读取最新」，重新核对并保存。
- **创建对局 422**：所选剧本与规则组合被原版引擎拒绝，主机命令窗口会显示详细原因；可关闭相关可选规则再试。
- **进入游戏后又想修改剧本**：点击页面右下角「返回联机准备大厅」，修改规则会启动**新的对局**，不会中途改动已有战斗的规则。
- **出现“只能访问本房间的已授权接口”**：不要走原版单机首页的「新建对局」按钮；请到 `/lan/lobby`，由服务器替双方创建。
- **连接失败**：检查服务器窗口是否仍在运行、Windows 防火墙是否允许 TCP 8765、双方设备是否在同一可信局域网。

## 安全与限制

- 原版后端 `8000`、Vite 开发端口 `5173` 仍应停止，不向局域网暴露。只对可信局域网开放网关 `8765`。
- 邀请链接相当于阵营密码，请分开保存；`backend/lan-duel-room.json` 含票据，切勿公开分享。
- 仅支持一个联机房间对应当前一场对局；新开一局不会删除旧存档，但旧局不再由该房间网关提供访问。
- 新页面与网关的**模拟接口测试通过**；尚未在你们实际的 Windows 双电脑和完整原游戏安装上完成端到端验证。

## 可选的离线测试

ZIP 内附带 `test_lan_duel.py`，它以模拟原版 API 运行合同测试，**不会操作原版数据库**：

```powershell
python -m pip install pytest httpx
python -m pytest -q test_lan_duel.py
```

## 回退

先关闭联机服务器，再执行：

```powershell
Copy-Item .\lan_server.py.before-lobby-v3.bak .\lan_server.py -Force
Copy-Item .\backend\lan-duel-room.json.before-lobby-v3.bak .\backend\lan-duel-room.json -Force
```

删除 `lan_lobby.html` 可选。前端和原版游戏库不受补丁本身影响。回退房间指针会回到升级前所指向的旧对局，仍然保留升级期间新建游戏的数据库记录。
