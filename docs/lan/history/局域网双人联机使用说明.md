# 铁底湾的回响 IV — 局域网双人对战补丁（第三方实验版）

适用对象：GitHub `fuxiaoji/iron-bottom-sound` 的 `main` 分支，尤其是 2026-11-10 线上查看的源码布局。**本 ZIP 是增量补丁，不包含原游戏源码，也不是独立安装包。**

> 状态：已对联机网关使用仿真 API 通过 4 项自动化测试（令牌、阵营锁定、订单双封存推进、跨站防护）及 Python 编译检查；当前环境无法完整下载原仓库，因此未进行原游戏端到端运行验收。原仓库后续升级可能导致补丁脚本拒绝修改源码（这是安全设计）。

## 1. 获取游戏与运行环境

在 Windows 10/11 上安装 Python >=3.11、Node.js >=20、pnpm。源码从 https://github.com/fuxiaoji/iron-bottom-sound 下载 ZIP 并解压，或使用：

```powershell
git clone https://github.com/fuxiaoji/iron-bottom-sound.git
cd iron-bottom-sound
npm.cmd install -g pnpm
```

确保根目录存在 `pyproject.toml`、`frontend/src/App.tsx`、`backend/src/iron_bottom_sound/api.py`。

## 2. 解压本补丁到游戏根目录

ZIP 中的 `lan_server.py`、`patch_frontend.py`、三个 `.bat`、本说明、`test_lan_duel.py` 均应放在与 `pyproject.toml` **相同的目录**，不要放在 `frontend` 或 `scripts` 子目录。

原项目之前启动过时，先在游戏根目录 PowerShell 执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/stop-game.ps1
```

严禁原版 8000/5173 端口还在监听时运行双人网关：原版端口没有阵营身份认证，会绕过联机隔离。本补丁启动时会检测本机的这两个端口并拒绝与它们同时运行。

## 3. 首次安装（只需一次）

双击 `安装联机补丁.bat`，它会依次执行：

```powershell
python -m pip install -e .
python patch_frontend.py
cd frontend
pnpm.cmd install
pnpm.cmd run build
cd ..
```

补丁修改 `frontend/src/App.tsx` 前会在同一目录备份为 `App.tsx.before-lan-duel.bak`，同时将备份及 `backend/lan-duel-room.json` 加入 `.gitignore`。安装脚本幂等，重复运行不会重复注入代码。

如果提示找不到 `pnpm.cmd`：先运行 `npm.cmd install -g pnpm`。

如果提示找不到 `frontend/src/App.tsx`：说明文件没有放到源码根目录。

如果补丁提示“源码锚点预期1处”，表示当前上游代码结构改变，**不要强行替换**，应按新版前端逻辑适配。

## 4. 开房启动

双击 `启动局域网双人对战.bat`。它默认使用内置想定 `IBS-S-03`、随机种子 1，首次启动创建一个双人房间；再次启动会加载保留的房间以及原存档。

控制台会分别输出轴心国和同盟国的邀请链接，形式为：

```text
轴心国（只发给玩家 A）：http://192.168.1.100:8765/join#xxxxxxxx
同盟国（只发给玩家 B）：http://192.168.1.100:8765/join#yyyyyyyy
```

地址 `192.168.1.100` 仅是示例。若打印了错误 IP，在主机 PowerShell 运行 `ipconfig` 查询对应 Wi-Fi/以太网的 IPv4，并替换邀请链接中的 IP（注意保留整个 `#` 及后面的票据）。

玩家 A、B 在同一局域网使用各自电脑的浏览器打开对应链接。服务器校验票据、设置仅 HTTP 访问的会话 Cookie，并重定向到现有完整 React 战场页面：

```text
http://主机IP:8765/?game=游戏UUID&side=axis&lan=1
http://主机IP:8765/?game=游戏UUID&side=allies&lan=1
```

只有第一次进入或清除 Cookie 后需要原邀请链接；重连继续使用对应邀请链接。**两名玩家不要互发完整邀请链接**。同一电脑测试两边时请使用不同的浏览器配置文件，否则 Cookie 会覆盖。

## 5. Windows 防火墙

以管理员身份启动 PowerShell，在**私人网络**（Private profile）中只放通 TCP 8765 给同网段设备：

```powershell
New-NetFirewallRule -DisplayName "IBS LAN Duel" -Direction Inbound -Protocol TCP -LocalPort 8765 -Profile Private -RemoteAddress LocalSubnet -Action Allow
```

确认电脑网络配置属于“专用网络”；若连的是访客 Wi-Fi、有 AP 客户端隔离，两台设备仍可能无法互相访问。不要进行路由器公网端口转发，不要将 8000/5173 端口开放到 LAN。

## 6. 双方如何操作

- 双方分别使用原版战场、自己的阵营查看权和原有建议订单功能。
- 任一方按原版按钮提交该阶段订单，网关仅接受本方 `side` 的订单。
- 第一个人封存后停留在自己的战场，并等待第二个人。双方各自电脑不切换座位。
- 第二个人封存后，网关调用原版引擎推进阶段，并继续处理无需双方填写订单的自动阶段。
- 两台电脑每约 1.8 秒重新查询自己的战场；新阶段自动显示，不必刷新浏览器。
- 若原版引擎校验失败，订单不会被网关伪造或绕过。查看控制台或登录后打开 `/lan/status` 查看状态与 `last_error`。
- 如阶段推进卡住且双方已封存，在已登录浏览器打开 `http://主机IP:8765/lan/control`，点击 **重试阶段推进**；**请勿直接调用原版 8000 端口**。

状态接口在已经用邀请链接登录的浏览器中访问 `http://主机IP:8765/lan/status`。如果返回 401，请重新使用邀请链接登录。

## 7. 新建其他想定 / 停止

要另开一局，先按 `Ctrl+C` 停止网关，再在游戏根目录执行：

```powershell
python lan_server.py --new-room --scenario IBS-S-01 --seed 42
```

也可直接双击 `新建联机房间.bat`（默认想定 IBS-S-03）。`--new-room` 会轮换双方票据并建立新对局；**旧游戏 SQLite 存档不会删除**，但旧的邀请链接会失效。

退出时在运行网关的窗口按 `Ctrl+C`。再次运行 `启动局域网双人对战.bat` 恢复此前房间。

## 8. 技术方案及边界

本补丁不修改 `backend/src/iron_bottom_sound` 的兵棋规则代码，也不直接读取或编辑该目录中的游戏 SQLite 数据。网关通过 `httpx.ASGITransport` 在**同一 Python 进程**调用现有 FastAPI 应用的 `/games/{id}/...` 接口，因此不需要独立公开 8000 端口。前端先构建到 `frontend/dist`，网关在 8765 上提供静态页面与受保护的 `/api`。

授权规则：两份 256 位令牌一一绑定 `axis` / `allies`，网关根据 HttpOnly Cookie 设置 `X-Player-Side`，拒绝其他对局、下载整个存档、调试世界态、AI 和管理员接口；订单 `side` 必须与凭证一致。提交与阶段推进由单进程 `asyncio.Lock` 串行化。引擎仍负责检查所有战术订单的合法性。

限制与安全注意：

1. 这是一房间、两阵营的最小可玩联机原型，不是带账号系统和匹配大厅的正式服务。
2. 联机网关使用明文 HTTP，适合可信任的本地家庭网络，不抵御 LAN 内抓包、设备被控制或令牌被共享；如果要通过互联网玩，需增加 HTTPS/TLS、反向代理和更严格的身份及部署方案。
3. 房间文件 `backend/lan-duel-room.json` 含双方可恢复的邀请凭证，只应由主机操作系统账户读取。不要将其提交到 GitHub 或发给对手。
4. 如果原版裁决出现未实现的想定特例或规则冲突，网关不会修正规则错误；可以通过状态接口检查和原游戏日志排查。
5. 未实现旁观者模式和战报下载；为防泄露未结束对局信息，主动封闭了这些原本没有鉴权的入口。
6. 未对这份第三方补丁做真实的双机端到端验收；已做本地模拟接口安全与同步测试。正式游玩前建议先用两台电脑完成几个阶段的冒烟测试。

## 9. 验证与卸载

模拟接口测试（需安装 pytest，可运行 `python -m pip install pytest`）：

```powershell
python -m pytest -q test_lan_duel.py
```

如要撤销前端补丁，在停止网关后运行：

```powershell
Copy-Item frontend/src/App.tsx.before-lan-duel.bak frontend/src/App.tsx -Force
```

再运行 `cd frontend; pnpm.cmd run build`。删除根目录 `lan_server.py` 等新增文件即可卸载联机网关。**不要删除原有的 backend/iron-bottom-sound.sqlite3**。
